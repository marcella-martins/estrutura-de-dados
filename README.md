# MC202
# Estruturas de Dados

Implementações de estruturas de dados em C, feitas durante a disciplina
MC202 na Unicamp (Engenharia de Computação, 2° semestre).

## Conteúdo

| `SEMANA_1` | Exercícios iniciais focados em linguagem C |
| `SEMANA_2` | Pilha e fila implementadas com vetor e com lista |
| `SEMANA_3` | Ordenação e desordenação com lista e comparação de cadeias |
| `SEMANA_4` | Pilha e fila implementadas com vetor |
| `SEMANA_5` | Árvore binária de busca |

## Como compilar e rodar

Precisa do `gcc` instalado. Exemplo, dentro de uma das pastas:

```
gcc -Wall -o programa main.c
./programa
```

## O que aprendi

- Alocação dinâmica de memória com malloc/free
- Ponteiros e structs
- Análise de complexidade das operações
- Árvores, pilhas e filas
